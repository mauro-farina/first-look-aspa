# submission-264-imc26

This repository contains the code used to obtain the results and generate plots and tables of the submitted paper.

Each notebook represents one of the three main result sections:
1. 1_Deployment.ipynb: time analysis and characterization of the adoption of ASPA;
2. 2_PathVerification.ipynb: adaptation of ASPA's path verification procedure, analysis of possible route leaks;
3. 3_ASRelationships.ipynb: comparison of providers inferred by CAIDA and BGPKIT against ASPA-declare providers.
