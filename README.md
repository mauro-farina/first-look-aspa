# A First Look at ASPA: Deployment, Route Leaks, and AS Relationships

This repository contains the code and data used to obtain the results and generate plots and tables for the paper.

## Notebooks

> Each notebook has a configuration cell where you must set whether to render figures with Latex or not.

### 1_Deployment
- Time analysis and characterization of ASPA adoption.
- All data required to run it is included in the repository.
- Produces the following results from the paper: Figures 2, 3, 4, 5, 6; Table 1.

### 2_PathVerification: 
- ASPA path verification and route leak analysis.
- Produces the following results from the paper: Figures 8, 9; Tables 3, 6.
- The notebook is structured into the following three subsections:

#### 2.1 Find route leaks
- Identify the 36655 invalid paths according to the algorithm presented in the paper
- Requires `data/caida/2026-03-paths.txt`, which is obtained by extracting unique AS Paths from `data/caida/2026-03-paths-detailed.txt`. Both are large files (2 and 40 GB respectively) and not included in the repository, though they can be download with our scripts (see below)
- The output of this section, `data/2026-03-invalid-paths.txt`, is included in the repository

#### 2.2 Minimal invalid paths
- Analyses of the Minimal Invalid Paths (MIPs) and their propagation

#### 2.3 Invalid paths over time
- Time analysis across March of invalid paths
- The results of our campaign of retrieving RRC data from targeted RRCs and parsing data from targeted vantage points are available in the repository: it is thus possible to reproduce Figure 8.
- Re-producing these results requires days of data processing even for powerful systems. An average laptop with 8 to 16 GB of RAM would likely take weeks, as parallelization is heavily RAM-bounded.

### 3_ASRelationships
- Comparison of CAIDA and BGPKIT providers vs ASPA-declared providers.
- Produces the following results from the paper: Figures 10, 11, 12; Table 4.

## Scripts

- get_caida_data.py
  - Download CAIDA AS Relationships, AS Cones, or paths.
  - Usage:
    - `python get_caida_data.py --rel`
    - `python get_caida_data.py --cone`
    - `python get_caida_data.py --paths`

- fetch_vaps.py
  - Download Validated ASPA Payloads from RIPE NCC RPKI archive.
  - Usage `python fetch_vaps.py [FROM] [TO]`
  - Writes to data/vaps.csv. 
  - Note that running this script *will* affect some of the results generated by the notebooks.

- get_rrc_vps.py
  - Extract the RRC vantage points that observed invalid paths.
  - Requires: data/caida/2026-03-paths-detailed.txt and data/2026-03-invalid-paths.txt.
  - Usage: `python get_rrc_vps.py --workers 4`
  - Output: data/target_rrc_vps.csv

- fetch_rrc_data.py
  - Download RRC RIBs and retain only invalid paths.
  - Requires: bgpkit-parser, data/target_rrc_vps.csv, data/2026-03-invalid-paths.txt.
  - Usage: `python fetch_rrc_data.py [YYYY] [MM] [DD] --cache-workers 8 --parse-workers 40`
  - Output: rrc/out/YYYY-MM-DD.txt
  - Note that this script requires large amounts of RAM to be run with more than one or two parse-workers. We originally run it with 40 parse-workers on a system with more than 300 GB of RAM.

## Related code

- aspa_verification.py contains the ASPA AS Path verification algorithms. Required in 2_PathVerification.ipynb to classify paths as Valid, Invalid, Unknown, or N/A.
